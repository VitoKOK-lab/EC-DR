# 選品清單：把抓商品資料那段放上 Cloudflare

> 十分鐘，一次做完，以後不用再管它。
> 做完之後，設計師貼完網址按「同步」，商品的名稱、照片、價格就會跑出來。

---

## 為什麼需要這個東西

官網**沒有開 CORS**。實際去試過：

```
回應裡沒有 Access-Control-Allow-Origin
/products.json  →  只是回同一頁 HTML，不是 JSON
/api/v1/...     →  全部轉走
```

意思是：**瀏覽器發出去的請求一定會被擋**，跟是不是設計師手動按的無關。
所以抓取一定要在瀏覽器以外的地方做。

三條路比過：Mac mini 去抓（會睡著，而且要每幾分鐘問一次資料庫）、
設計師電腦裝程式（Windows 要先裝 Python）、
Cloudflare（**沒人按就完全不動，按了才跑，不用裝任何東西**）。

選了第三條。

---

## 你要做的（只有這些）

- [ ] 1. 到 [dash.cloudflare.com](https://dash.cloudflare.com) 註冊一個免費帳號（有的話就登入）
- [ ] 2. 左邊選 **Workers & Pages** → **Create** → **Start with Hello World!** → **Deploy**
- [ ] 3. 進去按 **Edit code**，把整個編輯器內容**全選刪掉**，
      貼上 `cloudflare/shopline-proxy.mjs` 的**全部內容**，按 **Deploy**
- [ ] 4. 複製上面那個網址（長得像 `https://xxxx.workers.dev`）
- [ ] 5. 回系統「**設定 → 平台**」，貼進「抓商品資料的網址」那一格，存檔

做完了。設計師那邊什麼都不用裝。

---

## 確認它活著

把下面這串貼到瀏覽器網址列（把 `xxxx` 換成你的）：

```
https://xxxx.workers.dev/?url=https://www.tzgrotw.tw/products/自帶光芒｜手鏈｜天然歐泊
```

**應該看到**：

```json
{"ok":true,"name":"自帶光芒｜手鏈｜項鍊｜天然歐泊",
 "priceMin":990,"priceMax":3500,"listMin":6000,"listMax":15000,
 "variants":["自帶光芒｜白歐泊","自帶光芒｜黑歐泊", ...]}
```

看到 `"ok":true` 就成了。

## 幾件已經替你想過的事

**別人拿到這個網址會怎樣？**
沒事。那段程式**只准抓 `www.tzgrotw.tw` 的單一商品頁**，
別的網域、分類頁、活動頁、首頁一律擋掉。
拿它去抓別的網站只會拿到一句「只能抓 www.tzgrotw.tw 的商品頁」。

這一點很重要，因為這個專案的原始碼是公開的 —— 網址遲早會被看到。
沒有這道限制，它就是一個任何人都能用的免費跳板。

**會花錢嗎？**
免費額度是每天 10 萬次請求。你們一天大概用 30 次。

**會不會一直去打自己的官網？**
同一個商品網址五分鐘內只會真的去抓一次（其餘走快取）。
而且沒有排程 —— **沒人按就完全不動**。

**它掛掉會怎樣？**
設計師會看到「抓不到，請手動填名稱」，然後自己打商品名。流程不會卡死。

**官網改版怎麼辦？**
`tests/shopline-parse.mjs` 用一份真實頁面的樣本在守解析規則。
官網改掉那些結構，跑測試就會變紅 —— 不用等設計師來回報。
