# 選品頁的設計稿

這裡是**設計稿的原始檔**，不是程式。畫面本身在 `app.js` 的 `viewCurate()`。

| 檔案 | 是什麼 |
|---|---|
| `Main.dc.html` | 卡片模式（電腦） |
| `List.dc.html` | 列表模式（電腦） |
| `Phone.dc.html` | 手機 |
| `canvas.json` | 三塊畫板在畫布上的位置與說明 |

## 為什麼留著

改設計的時候從這裡改，比直接改程式快 —— 可以先看樣子、比兩個版本，
決定了再做進 `app.js`。

## 怎麼重新產生可以看的檔案

產出檔（`curation-page-design.html`，約 2.5 MB，整個編輯器包在裡面）
**刻意不進版本庫**（見 `.gitignore`）。要重新產生，用 Claude Code 的
`/design` 工具從這四個檔案重新組一次。

## 設計上定案的幾件事

- **月份是可切換的標籤**，不是一路往下捲。每個月旁邊標幾個品。
- **兩種模式**：卡片（挑品，看圖）／列表（處理一整批，欄位對齊掃得快）。
  列表模式下「貼網址」那張卡收成一條，按「展開」才長出來。
- **四種狀態都要畫得出來**：已抓好、還沒抓（琥珀）、抓不到（紅，
  而且要給「自己填名稱」的路，不能是死路）、選過兩個月。
- 配色、字體、按鈕**沿用系統現有那一套**（古金 `#8A7338`、襯線標題配
  金髮絲線、深色主鈕），不另外長一個樣子。
